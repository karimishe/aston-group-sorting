# Каркас приложения

Каркас — рабочая версия с одним источником данных, одним компаратором и одним алгоритмом. Она нужна команде как основа для остальных реализаций.

## Что готово

| Часть | Классы |
| --- | --- |
| Запуск и консольное меню | `Main`, `ConsoleApplication`, `ConsoleInput` |
| Модель с проверкой полей | `Car`, `Car.Builder` |
| Общая коллекция | `MyArrayList<T>` |
| Загрузка из файла | `FileCarSource`, `CarLineParser` |
| Сравнение по трём полям | `CarAllFieldsComparator` |
| Сортировка вставками | `InsertionSort<T>` |
| Создание и подключение реализаций | `Modules` |

Пользователь выбирает файл и количество записей, запускает сортировку и просматривает результат. Алгоритм получает копию коллекции, поэтому исходный порядок сохраняется. При ошибке загрузки прежние данные и результат остаются доступными. Новая успешная загрузка сбрасывает результат сортировки.

В подменю уже есть ручной ввод, генератор, сортировки выбором и пузырьком. Пока эти пункты только сообщают, что функция не реализована, и возвращают в главное меню.

## Перед передачей команде

- Проверить сборку и запуск по README, включая ошибочный ввод и плохой файл.
- Запустить тесты модели, коллекции, источника, компаратора, алгоритма и меню.
- Просмотреть изменения и объединить `feature/core` в `main`. Участники создают свои ветки от обновлённого `main`.

## Следующие задачи

Команда добавляет оставшиеся источники, компараторы и алгоритмы по [плану разработки](development-plan.md). До готовности ручного и случайного ввода основное задание ещё не завершено. Дополнительные задания выполняются после основной части и не должны мешать работе файлового сценария.

`MyArrayList<T>` уже используется всеми модулями. По условию собственная коллекция нужна для задания `3*`; её наличие пока не означает, что заполнение через Stream реализовано. Правило равенства автомобилей через `equals` и `hashCode` потребуется позже, для подсчёта совпадений.

Подробности устройства программы — в [архитектуре](architecture.md), требования к реализациям — в [контрактах модулей](contracts.md).
